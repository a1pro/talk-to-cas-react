# TALK TO CAS Frontend

Clean React + TypeScript frontend focused on:
- User dashboard
- Merchant dashboard
- Admin dashboard

## Setup
1. `npm install`
2. `cp .env.example .env`
3. Set `VITE_API_BASE_URL=http://127.0.0.1:8000/api/v1`
4. `npm run dev`

## Demo logins
- Admin: `admin@talktocas.com` / `password`
- Merchant: `merchant@talktocas.com` / `password`
- User: `user@talktocas.com` / `password`
